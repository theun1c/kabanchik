# kabanchik

A simple learning project for building a Kanban board backend.

The main goal of this project is to learn how to build a basic backend application with a new stack while implementing a small but realistic feature set:
- status columns
- tasks
- moving tasks across columns
- reordering tasks inside a column

## Tech Stack
- TypeScript
- Node.js
- NestJS
- PostgreSQL
